# JetBrains Mono

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), downloaded 2026-10-05.

The upright variable font was instantiated at weights 400, 500, 600, 700 and 800 using fontTools, with static family/style names. The TTF files and SIL Open Font License are embedded by Projucer. No network request is made by the plugin. SF Mono is the system fallback and is not redistributed.
